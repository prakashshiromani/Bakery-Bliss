# Bakery-Bliss

A premium artisan bakery website template featuring a hero video, responsive design, and smooth scroll animations.

## Features

* **Hero Video Background:** Engaging visual experience on the landing page.
* **Responsive Design:** Optimized for mobile, tablet, and desktop devices.
* **Premium Aesthetics:** Elegant color palette (**Gold & Dark Brown**) and typography.
* **Pages Included:**
  * Home (`index.html`)
  * Menu (`menu.html`)
  * Login (`login.html`)
  * Sign Up (`signup.html`)
  * Terms of Use (`terms.html`)
  * Privacy Policy (`privacy.html`)
